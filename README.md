## 日本語

**Cala's Pokecom BASIC** は、ClockworkPi PicoCalc および Raspberry Pi Pico 2 W / RP2350 向けの、RetroMiniBASICを基盤とした独立動作のBASIC環境です。

### リリース

一般利用者向けの正式な配布はGitHub Releasesで行います。各リリースには、対応するUF2バイナリ、サンプルプログラム、標準設定ファイルをRelease Assetsとして添付します。

開発作業および中間ビルド成果物は別に管理し、このリポジトリでは公開しません。

### ドキュメント

利用者向けドキュメントは、このREADMEおよび `docs/` 以下でGit管理します。

## English

**Cala's Pokecom BASIC** is a standalone BASIC environment based on RetroMiniBASIC for ClockworkPi PicoCalc and Raspberry Pi Pico 2 W / RP2350.

### Releases

GitHub Releases are the official distribution channel for end users. Each release will provide the relevant UF2 binaries, sample programs, and standard configuration files as Release Assets.

Development work and intermediate build artifacts are managed separately and are not published from this repository.

### Documentation

User documentation is maintained in this README and under `docs/`, both under Git version control.
