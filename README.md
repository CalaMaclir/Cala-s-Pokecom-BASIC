# Cala's Pokecom BASIC

Official public distribution repository for **Cala's Pokecom BASIC**, a standalone BASIC environment based on RetroMiniBASIC for:

- ClockworkPi PicoCalc
- Raspberry Pi Pico 2 W / RP2350

## Releases

GitHub Releases are the official distribution channel for end users. Each release will provide the relevant UF2 binaries, sample programs, and standard configuration files as Release Assets.

Development work and intermediate build artifacts are managed separately and are not published from this repository.

## Documentation

User documentation will be maintained in this repository, primarily in this README and under `docs/`.
