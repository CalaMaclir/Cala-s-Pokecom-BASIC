# セキュリティ方針 / Security Policy

## 日本語

セキュリティ上の脆弱性を発見したと思われる場合は、公開Issueへ報告しないでください。また、認証情報、秘密鍵、具体的な攻撃手順を公開の議論に含めないでください。

このリポジトリでGitHubのPrivate Vulnerability ReportingまたはGitHub Security Advisoryを利用できる場合は、それらの非公開経路を使用してください。利用できない場合は、脆弱性の詳細を記載せず、非公開の報告経路を求める最小限の公開Issueを作成してください。

## English

If you believe you have found a security vulnerability, please do not report it in a public Issue and do not include credentials, private keys, or detailed attack instructions in public discussions.

Use GitHub's Private Vulnerability Reporting or a GitHub Security Advisory for this repository when available. If neither private reporting route is available, please open a minimal public Issue requesting a private reporting channel without disclosing vulnerability details.
