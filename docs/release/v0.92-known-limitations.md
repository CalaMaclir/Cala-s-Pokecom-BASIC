# Version 0.92 Known limitations

| 種類 | 制限／取扱い |
|---|---|
| Source | PSRAM INTERNAL／SD:1024行×2047文字、SRAM fallback:256×191。Direct191文字 |
| Compile | IL1536 slots、string pool6144 bytes、global64。source容量内でも上限になる |
| Functions | 32関数、8parameters、128scalar locals（parametersを含む）、depth16、strings127文字 |
| Memory | 必要なframeだけSRAMへ確保。巨大string frameはdepth16前にOOM。戻り／error／BREAKで解放 |
| Editor | PSRAMなしではUndo／Redo非対応。履歴はsession-only、256 KiB |
| Files | 区切り含むroot-relative79文字、ASCII英数字／_／-／.／内部space。..、先頭末尾space/dot、重複separator等拒否 |
| Save | BAS改行はLF。Structuredはblank/indent/order保持、表示番号を保存しない |
| Mode | 同一fileでClassic／Structured混在は拒否。Structured StoredはEditor編集、Directは即時実行 |
| Unsupported | FUNCTION内配列（local/GLOBAL）、SUB／labels／STATIC／optional／overload／modules |
| Standby | RAM保持で完全電源断ではない。BIOS1.7での確認は他BIOSの保証や更新強制を意味しない |
| Measurement | 実機compile-only/cache-only・stack/heap high-water未計測。Host値は実機速度ではない |
| Deferred | DATA/READ/RESTORE、INPUT強化、File I/O、TRACE/Debuggerはv0.93候補。OTA/native compilerは今回対象外 |

安全性・正当性に関する未解決gateはこの表へ移して解消扱いにしない。最終CI／配布audit失敗はRELEASE BLOCKER。最終binaryの代表smokeはFINAL DEVICE SMOKEとして受入済み機能とは別記する。
