# Cala's Pokecom BASIC Version 0.85

## 日本語

Version 0.85は、v0.81以降のRTC／I2C、PCG、audio、Storage Continuityへ、Bluetooth Classic SPP、firmware update UX、SD long-line supportを統合した正式releaseです。

### Highlights

- Bluetooth Classic SPP device `CPB-PicoCalc`
- Bluetooth BASIC Console、Test Terminal、XMODEM／YMODEM
- File Transfer: AUTO／USB CDC／UART0／Bluetooth SPP
- PC→PicoCalc YMODEM single-file／multi-file batch receive
- Control CenterからEnter BOOTSEL／Reboot
- Windows `flash-cpb.cmd`
- SD Program Storage: 1,024 lines × 2,047 body characters
- 3 voice MML、PCM WAV、8×8 mono／indexed-color PCG
- Key Click OFF／SOFT／CLASSIC／SHARP
- Storage ContinuityとUSB Storage return recovery
- external artifact: `CPokecombasic.uf2`／`CPokecombasic-pico2w`

### Compatibility / Installation

正式対応はClockworkPi PicoCalc + Raspberry Pi Pico 2 Wです。Pico／Pico W／Pico 2は配布対象外です。古いCPBから最初に更新するときは物理BOOTSEL操作が1回必要です。Version 0.85導入後はFirmware menuと`flash-cpb.cmd`を利用できます。

### Known limitations

- 同時Bluetooth SPP clientは1つ
- YMODEM senderはsingle-file
- PicoCalc interactive line inputとDirect modeは191 characters
- runtime heap／stack high-water markは実機未計測

## English

Version 0.85 is the formal release that brings Bluetooth Classic SPP, firmware-update UX, and SD long-line support together with the RTC/I2C, PCG, audio, and Storage Continuity work introduced after v0.8.

### Highlights

- Bluetooth Classic SPP device `CPB-PicoCalc`
- Bluetooth BASIC Console, Test Terminal, XMODEM, and YMODEM
- File Transfer over AUTO, USB CDC, UART0, or Bluetooth SPP
- PC-to-PicoCalc YMODEM single-file and multi-file batch receive
- Enter BOOTSEL and Reboot from Control Center
- Windows `flash-cpb.cmd`
- SD Program Storage: 1,024 lines × 2,047 body characters
- Three-voice MML, PCM WAV, and 8×8 mono/indexed-color PCG
- Key Click OFF, SOFT, CLASSIC, and SHARP
- Storage Continuity and USB-storage return recovery
- External artifact names `CPokecombasic.uf2` and `CPokecombasic-pico2w`

### Compatibility / Installation

Official support is limited to ClockworkPi PicoCalc with Raspberry Pi Pico 2 W. Pico, Pico W, and Pico 2 are not release targets. The first upgrade from older CPB firmware requires one physical BOOTSEL operation. After Version 0.85 is installed, the Firmware menu and `flash-cpb.cmd` are available.

### Known limitations

- One simultaneous Bluetooth SPP client
- YMODEM sending is single-file
- PicoCalc interactive input and Direct mode remain limited to 191 characters
- Runtime heap/stack high-water mark has not been measured on hardware
