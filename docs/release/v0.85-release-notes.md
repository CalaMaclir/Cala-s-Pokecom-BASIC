# Cala's Pokecom BASIC Version 0.85 Release Notes

Version 0.85は、v0.81以降に追加されたRTC／I2C、PCG、audio、Storage Continuityへ、Bluetooth Classic SPPとfirmware update UX、SD long-line supportを統合した正式版です。

## Highlights

- Bluetooth Classic SPP device `CPB-PicoCalc`
- Bluetooth BASIC Console、Test Terminal、XMODEM／YMODEM
- File Transfer transport：AUTO／USB CDC／UART0／Bluetooth SPP
- PC→PicoCalc YMODEM single-file／multi-file batch receive
- Control CenterからEnter BOOTSEL／Reboot
- Windows `flash-cpb.cmd`
- SD Program Storage 1024 lines × 2047 body characters
- 3 voice MML、PCM WAV、background audio改善
- 8×8 mono／indexed-color PCG
- Key Click OFF／SOFT／CLASSIC／SHARP
- Storage ContinuityとUSB Storage return recovery
- external artifact：`CPokecombasic.uf2`／`CPokecombasic-pico2w`

## Compatibility

対象はClockworkPi PicoCalc + Raspberry Pi Pico 2 Wです。Pico／Pico W／Pico 2は配布対象外です。内部互換file名`RMBASIC.*`とrepository／target名は維持します。

## Installation note

古いCPBから最初に更新するときは物理BOOTSEL操作が1回必要です。Version 0.85導入後はFirmware menuと`flash-cpb.cmd`が利用できます。

## Known limitations

- 同時Bluetooth SPP clientは1つ
- YMODEM senderはsingle-file
- PicoCalc interactive line inputとDirect modeは191 characters
- runtime heap／stack high-water markは実機未計測
