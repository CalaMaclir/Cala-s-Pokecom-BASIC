# Cala's Pokecom BASIC v0.94 Release Notes

v0.94は既存のClassic／Structured BASICを維持し、画像I/O、Files音声操作、診断、Editor、Program保護を改善した正式版です。Stage 1～11の最終実機受入は2026-10-04にプロジェクト所有者が承認しました。具体的な受入対象と公開buildはRelease checklistおよび公開記録へ対応付けます。

## Files / Audio

停止／pauseキーのpressとrepeatを1つの入力層で処理し、ESC停止後の意図しないdirectory移動を防ぎます。Filesの再生状態、現在file、停止操作と再描画を整えました。Audio停止後の10秒grace、bias ramp、ラッチ確認により既存の省電力復帰・プチノイズ対策を保持します。

## System / Diagnostics

共通snapshotによるSystem Information、Diagnostics、USB Serial report、Last Errorを搭載します。REPLのINFOとLASTERRORは同じ情報源を利用します。信頼できるHeap値を取得できない場合はN/Aと表示します。表示・exportだけでSD再mountやkeyboard resetを行わず、保存passwordやsource本文をSerial reportへ出力しません。

## Graphics

LOADIMAGE filename$[,x,y]で24-bit uncompressed BMPを等倍読込みします。SAVEIMAGE filename$[,x1,y1,x2,y2]を正式な保存構文とし、SAVE IMAGEを同じILへ正規化して互換を維持します。Classic／Structured両方で利用可能です。LOAD／SAVEはProgram用REPL commandです。画像path、storage ownership、clipping、破損BMPとwrite failureを確認します。

## Runtime / Editor

Compile／Runtime Errorのtype、Classic行番号／Structured source row、取得可能なsource preview、FUNCTION traceを表示します。EDITは未変更のerror位置へ移動します。StructuredのEnterは4-space indent、入力したcloser／branchの整列、atomic Undoに対応します。Last Errorは最新失敗で置換し、成功／BREAK後も保持します。

## Program Safety

dirtyとprogram名の*を共通化し、NEW／LOAD／Files／quick key／New ProgramでSave／Discard／Cancelを確認します。保存成功後のみcleanにし、Save／Load失敗・Cancel後は元のprogramを保持します。Undoで保存済みstateへ戻ればclean、Redoでdirtyへ戻ります。

## BASIC Enhancements

DATE$()、TIME$()、TRIM$、LTRIM$、RTRIM$、REPLACE$、SPACE$を追加しました。日時は設定済みRTC／software clockを読込みます。括弧付き関数により既存のDATE$／TIME$変数を保持します。文字列の型・引数・長さ上限、日時未取得のエラーを確認します。

## Build / CI / Stability

keyboard-i2c-recovery独立workflowは手動実行のみ。通常firmware内の受動回復は維持します。反復BASIC、画像の実ファイルI/O、保存保護、Files／Audio、Error／Editor、read-only診断のhost試験を恒久化しました。通常CIにはrecovery／performance用UF2を含めず、配布packageからELF／map／object／nested ZIPを除外します。元のActions ZIPと1回展開後の配置・hash・manifestを検証します。v0.94マニュアル3冊と対応バッジ、HELP、READMEを揃えました。

## Compatibility / Breaking Changes

No intentional breaking changes relative to v0.93. SAVE IMAGE互換と既存programのLOAD／SAVEを維持します。v0.92以前から移行する場合は、v0.93で導入されたLOGの底10への変更に注意し、自然対数はLNを使ってください。SUB、汎用BASIC File I/O、周期Autosave、OTAは今回も追加しません。

## Known Issues / Limitations

今回のリリースで新たなfirmware不具合は確定していません。[現行制限](v0.94-known-limitations.md)を参照してください。実機未確認事項を既知不具合やPASSとして扱いません。

## Installation / Provenance / Assets

PicoCalc + Pico 2 W専用、Pico SDK 2.3.1。正式公開の対応は[公開記録](v0.94-release-checklist.md)を参照してください。成功したCIが生成する完全artifact ZIPをそのまま使用し、通常UF2、Install／System／Programming Reference PDF、SHA256SUMS.txtを準備します。flash-cpb.cmdは完全ZIP内だけで配布し、build/CPokecombasic.uf2との配置を維持します。ZIPを1回展開すれば利用できます。

最終source／tested merge／branch head SHA、build番号、run ID、UF2／PDF hashとhost結果はbuild/firmware-manifest.json、package hashはbuild/package-audit.jsonに記録します。元のZIP自体のSHA-256はdownload後に記録します。具体的な成功runと実機確認は[Release checklist](v0.94-release-checklist.md)に対応付け、正式tag／Release時に公開用commitとともに追記します。
