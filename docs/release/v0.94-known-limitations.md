# Version 0.94 Known Limitations / Migration Notes

| 種類 | 制限／取扱い |
|---|---|
| Numeric type | `BasicNumber=float`のsingle precision。真のINTEGER型と`A%`はない |
| Integer exactness | floatがすべての整数を厳密に保持できるのは`|value| <= 2^24`。`\`、`<<`、`>>`、`XOR`はint32へ一時変換後floatへ戻す |
| LOG migration | v0.93の`LOG`は底10。v0.92以前の自然対数目的の`LOG`は`LN`へ変更 |
| Source | PSRAM INTERNAL／SD: 1024行×2047文字、SRAM fallback: 256×191。Direct／prompt入力は191文字 |
| Compile | IL 1536 slots、literal string pool 6144 bytes、global symbol 64。source容量内でも上限になり得る |
| Functions | 32 FUNCTION、8 parameters、128 scalar locals（parameters含む）、call depth 16、string 127文字 |
| Function arrays | FUNCTION内のlocal array、GLOBAL array accessは非対応 |
| Structured branches | Structuredで`GOTO`、`GOSUB`、`ON ... GOTO/GOSUB`、Classic GOSUB用`RETURN`は非対応 |
| Classic constructs | Classicでblock IF、Structured FUNCTION／GLOBAL／RETURN expression、EXIT、SELECT CASEは非対応 |
| DATA | Direct mode非対応。DATAはliteralのみ。`RESTORE line`／label／function指定は非対応 |
| SELECT CASE | `CASE IS`、比較条件、variable／function criterion、文字列range、fallthroughは非対応 |
| Editor | PSRAMなしではUndo／Redo非対応。履歴はsession-only、256 KiB |
| Text | 日本語入力、漢字表示用font／dictionary／変換systemは正式機能に含まない |
| Files | SD root相対pathは区切り込み79文字。非ASCII、`..`、不正separator等を拒否 |
| Wi-Fi | 2.4 GHz WLAN。最大5 profile。password入力時は文字をvisible表示。masterはbootごとにOFF |
| Audio | 対応外sample rate／compressed WAV／24-bit WAVは非対応。hardware・file依存 |
| Compiler | BASIC native compilerはない。v0.94はVM実行 |
| Deferred | SUB、labels、STATIC、optional parameter、overload、module、BASIC File I/O、TRACE／Debugger、OTAは未実装 |

未確認事項を既知不具合として扱いません。Host testの合格はPicoCalcの電気的・実時間挙動そのものの証明ではなく、実機確認結果はrelease recordで区別します。

## v0.94 additions

画像は24-bit uncompressed BMPのみ。image load/save先はSDで、INTERNAL Program Storageへ画像保存はできません。SAVEIMAGE失敗時に不完全なBMPが残る場合があります。Heapは信頼できる値がない場合N/Aです。LASTERRORはboot内の最新1件を保持し、FUNCTION traceは最大4件。音のプチノイズや電力はhost modelでは確定できず実機確認が必要です。

今回のhost安定性試験では新たなfirmware不具合は確定していません。最終Stage 10～11候補は2026-10-04に所有者が実機受入済みです。公開buildへの対応と新規実測の有無はRelease checklistへ記録します。
