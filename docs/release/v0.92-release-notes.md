# Cala's Pokecom BASIC System Version 0.92

正式公開日: 2026-10-02（日本時間）。tag: v0.92.0。前回の正式公開版はv0.90.0（2026-09-28 UTC）。v0.91の正式Releaseは存在せず、その開発改善を今回まとめて提供する。

## v0.90からの主な変更

- v0.91: USB CDC／UART転送のbulk化、UART 230400／460800／921600 bps、任意RX DMA、YMODEM受信・送信効率改善。Serial Config／File Transferなどメニュー整理。
- v0.91: PSRAM multi-client allocator、INTERNAL ProgramStore 1024×2047、DirectState／Compiled Program Cache、SD cache、LIST中断とLOAD／RUN進捗。
- Stage 0.5: STANDBYでLCD Display OFF／Sleep IN、復帰時のDisplay ON／明るさ復元。BIOS1.7・build696で消灯／復帰を10回連続確認。
- Stage 1: Editor Enter分割・行頭insert-before・Backspace／Delete連結、Classicの手動採番、Undo／Redo。フォルダー作成・移動・改名・空削除、128項目超のFiles、長いパスの表示省略。
- Stage 2: 行番号なしStructured BASIC、block IF／ELSEIF／ELSE／END IF、数値・文字列FUNCTION、値渡し・forward call・再帰、local-by-defaultと明示GLOBAL。Editor表示番号00001＋2spaces、継続行番号欄blank、Tab、compile-error移動。
- Stage 3: Filesの6文字属性欄、フォルダー行全体配色・選択優先、表示用ルートslash、F-key basename。compilerの不要走査削減、local融合、FUNCTION有無別VM、Cache format3と検証。BASICは引き続きVM実行で、単精度・既存丸めを維持。
- Stage 3C: 原稿・正式PDF3本、サンプル説明、統合CI、受入済み3AB baselineとの比較、配布物の個人パス除去とchecksum準備。

## 導入・互換性

PicoCalc＋Pico2Wが対象。完全Actions ZIPを全展開し、rootのflash-cpb.cmdとbuild/CPokecombasic.uf2を維持する。Windows updaterはpicotool.exeをPATHへ置き、serialを閉じUSB StorageをCPBへ返して実行する。通常版UF2単独も同じartifactから抽出して提供する。

更新前はBAS・RMBASIC.CFG等をバックアップする。SD全初期化は通常不要。session v1はClassicとして読み、v2へ移行する。Compiled Cache format3はsessionと別形式で、旧／破損cacheはmissとして再compileする。StructuredとClassicを同一fileへ混在させない。Stored Structured sourceはEditor経由で編集し、promptはDirect実行に使う。

BIOS1.7はSTANDBYの確認構成であり、全ユーザーへBIOS更新を強制する条件ではない。STANDBYはRAM保持待機で完全電源断ではなく、消費電力の実測保証はない。

## 制限

[Known limitations](v0.92-known-limitations.md)とProgramming Reference参照。FUNCTION32、parameter8、local128、depth16、strings127、globals64、IL1536／pool6144。大きいstring frameはdepth16以前にOOMとなり得る。PSRAMなしではUndo／Redoなし。DATA／READ／RESTORE、INPUT強化、File I/O、TRACE／Debuggerはv0.93候補。SUB、labels、STATIC、local配列、OTA、native compilerは対象外。
