# Cala's Pokecom BASIC v0.90 リリースノート

## 概要

v0.90 は、日常的なプログラム編集とファイル管理を中心に、PicoCalc 単体での制作体験を大幅に強化するリリースです。Full-Screen BASIC Editor、コマンド履歴、PSRAM を用いた Undo / Redo、WAV / MP3 再生、CPU切替時の無線サービス自動復旧、長い行・SD表示の性能改善をまとめています。

## 主な変更

### Stage 1 — 操作とFiles

- `BASIC>` に 24 件の session-only command history を追加
- Up / Down で履歴移動、編集中 draft を復元
- スクロール一覧で Shift+Up / Shift+Down のページ移動
- Files に PROGRAMS / DIRECTORY 表示、Rename、Delete、Info、Refresh を追加

### Stage 2 — Full-Screen BASIC Editor

- `EDIT`、Control Center、Files の `E` から起動
- ProgramStore を直接編集し、SD では1行本文2,047文字を保持
- Save、Save As、Find、Next、Goto、Insert Line、Delete Line
- logical line を画面幅へ visual wrap

### Stage 3 — PicoCalc PSRAM

- 8 MiB PSRAM の任意検出と System Information 表示
- Quick 1 MiB、Full、3-pass stress 診断
- 未搭載・検出失敗時も SRAM / SD の通常機能を継続

### Stage 4 — Editor Undo / Redo

- PSRAM 128 KiB を使用する session-only Undo / Redo
- おおむね31件ずつの coalesced undo / redo 履歴
- BASIC プログラム本体は従来どおり ProgramStore に保持

### Stage 5 — WAV / MP3と音量

- `WAVPLAY` を WAV / MP3 の内容判定再生へ拡張
- MP3 は 44.1 / 48 kHz、mono / stereo の streaming 再生
- Files の DIRECTORY から `P` で WAV / MP3 を再生・停止
- Master、WAV/MP3、PLAY の3層音量
- MP3 開始時に 200 MHz を自動要求し、停止後に元のclockへ復帰
- CPU profile 切替時に必要な Wi-Fi / Bluetooth / LED service を自動再起動

### Stage 6 — 性能とファイル名

- エディタの cursor-only fast path と key-repeat throttling
- SD viewport 読み込みを1回の lease / open / close に集約
- 内部空白を含む ASCII ファイル名に対応（最大79文字）
- 選択中ファイル名の LOAD / RUN / EDIT 補完
- 性能測定専用 `CPokecombasic-editor-perf.uf2` を CI artifact に追加

## 互換性と移行

- BASIC 言語の既存プログラムとの互換性を維持します。
- `WAVPLAY` の文法は同じで、対応内容が WAV / MP3 に拡張されました。
- CPU profile、Wi-Fi 接続状態、Bluetooth 接続状態、command history、editor history は再起動後に保持されません。
- 191文字を超える SD の logical line は RAM backend へ切り替えられません。元の SD source は保持されます。
- v0.90 の Files は root-only です。

## 既知事項

- ファイル名の case-only rename は SD / FAT の条件により期待どおりにならない場合があります。
- Full-Screen Editor の Undo / Redo は PicoCalc PSRAM が必要です。
- USB Mass Storage 動作中は CPU profile を切り替えられません。
- PSRAM 診断は PSRAM 内容を上書きします。エディタを終了してから実行してください。
