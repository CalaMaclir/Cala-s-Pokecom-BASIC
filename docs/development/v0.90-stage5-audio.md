# Version 0.90 Stage 5 Audio

## Scope

- Control CenterのFiles一覧で、WAVまたはMP3を選択して `P` で再生／停止する。
- 既存の `WAVPLAY` をcontent-awareに拡張し、RIFF/WAVEは従来decoder、その他はMP3 decoderで判定する。
- MP3はSDからstreaming decodeし、file全体をRAMへ読み込まない。
- MP3再生開始時は200 MHzを自動要求し、停止またはqueue drain後に元のclockへ戻す。
- Power／CPU menuからのPLL transitionでは、CYW43 serviceを内部で停止・再初期化し、LED、Wi-Fi、Bluetoothを可能な範囲で自動復帰する。
- Files画面は再生中のdirectory一覧をcacheし、streaming用storage lockを誤って`STORAGE BUSY`として表示しない。
- `PLAY` synthはsingle voiceを大きくし、最大3 voiceでもPCM clipしないheadroomを共有する。
- 音量はMaster、WAV／MP3、PLAYの三層とし、WAV／MP3のPWM基準gainは25%から50%へ拡張する。

## Supported audio

| Source | Format | Sample rate | Channels | Volume |
|---|---|---:|---:|---|
| `WAVPLAY` / Files | PCM WAV 8/16-bit | 11.025/22.05/44.1 kHz | 1/2 | Master × WAV/MP3 |
| `WAVPLAY` / Files | MPEG Audio Layer III | 44.1/48 kHz | 1/2 | Master × WAV/MP3 |
| `PLAY` | MML square wave | 22.05 kHz internal | mono | Master × PLAY |
| `BEEP` | square wave | 22.05 kHz internal | mono | Master |

MP3 decoderは[minimp3](https://github.com/lieff/minimp3)を使用する。vendored sourceはCC0-1.0。

## UI

FilesのDirectory modeでWAV/MP3を選択し、`P`を押す。再生中は `Playing: filename` を表示する。同じfileで再度 `P`、またはBREAKで停止する。選択位置とcached directoryを維持し、Filesを閉じる、modeを変える、refreshする、rename/deleteする場合は先にpreview再生を停止してstorage lockを解放する。

## Verification

Host test:

- WAV parser／resampler／buffer policy
- WAV/MP3 filename policyとRIFF header detection
- 75/100/150/200 MHz PWM timing
- `PLAY` single voiceおよび3 voiceのpeak値
- 25% output ceilingと独立volume

実機確認:

- WAV 11.025/22.05/44.1 kHz、8/16-bit、mono/stereo
- MP3 44.1/48 kHz、mono/stereo、CBR/VBR、ID3あり
- 長時間MP3でunderrun、heap劣化、SD lock残留がないこと
- 再生中のFiles scroll、停止、再選択、SD removal
- CPU 75/100/150 MHzからMP3を開始し、停止後に元のclockへ戻ること
- Wi-Fi/Bluetooth初期化後のsafe fallback
- `PLAY` 1/2/3 voiceとBEEP、Key Click、WAV/MP3の聴感比較
