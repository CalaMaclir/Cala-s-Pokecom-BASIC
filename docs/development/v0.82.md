# Version 0.82 development notes

> This document records the Version 0.82 development stage. For final Version
> 0.85 behavior, see [v0.85.md](v0.85.md) and [manual-ja.md](../manual-ja.md).

Version 0.82 adds hexadecimal numeric literals, external I2C/RTC support, and
programmable 8x8 graphics characters.

## Numeric literals

`&H` and `&h` introduce hexadecimal integers in normal numeric expressions.

## External I2C and RTC

- Controller: I2C0
- SDA/SCL: GP4 / GP5
- Speed: 100 kHz
- Logic: 3.3 V
- RTC sources: AUTO, EXTERNAL, INTERNAL, OFF
- RTC type: PCF8563
- RTC target address: configurable from 0x08 through 0x77
- BASIC: `I2C SCAN`, `I2CREAD(address,register)`,
  `I2CWRITE address,register,value`

External I2C uses 3.3 V logic. Do not apply 5 V to GP4/GP5. External devices
normally require suitable external pull-up resistors.

## Programmable graphics characters

`GLOCATE X,Y` selects an independent graphics-text cursor in pixel
coordinates. `GPRINT` draws 8x8 characters only to the LCD graphics surface.

- `GDEF "A"="183C66667E666600"`: 1-bit glyph, current graphics color
- `GDEF "A"="<128 hex characters>"`: 64 palette indices
- `GDEF "A"=""`: reset one character
- `GDEF CLEAR`: reset all characters
- `GPALETTE n,r,g,b` or `GPALETTE n,&Hrrggbb`
- `GPALETTE RESET`

Palette index 0 is transparent. Indices 1-255 are colors.

## Real-device checks

- External PCF8563 and AUTO/internal fallback
- I2C SCAN, I2CREAD, I2CWRITE, NACK/timeout behavior
- Pixel placement and text-console independence of GLOCATE/GPRINT
- Built-in, 1-bit PCG, indexed-color PCG, and transparency
- Keyboard, battery reading, internal RTC, and CPU profile changes
