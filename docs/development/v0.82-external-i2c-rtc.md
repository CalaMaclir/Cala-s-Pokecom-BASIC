# Version 0.82 development — External I2C / RTC

> This document records the Version 0.82 development stage. For final Version
> 0.85 behavior, see [v0.85.md](v0.85.md) and [manual-ja.md](../manual-ja.md).

- External I2C: I2C0, SDA GP4, SCL GP5, 100 kHz.
- External I2C uses 3.3 V logic. Do not apply 5 V to GP4/GP5.
- RTC source: AUTO (external then internal), EXTERNAL, INTERNAL, or OFF.
- RTC address is the CPB target address (7-bit, 0x08–0x77), default 0x51; it does not reprogram the RTC IC.
- Supported RTC: PCF8563.
- BASIC: `I2C SCAN`, `I2CREAD(address,register)`, and `I2CWRITE address,register,value`. BASIC accesses only I2C0.
- Real-device checks: external RTC, internal fallback, I2C scan/read/write, keyboard, battery, and CPU profile operation.
