# Version 0.85 Bluetooth Stage 1

> This document records the development stage. For final Version 0.85 behavior,
> see [v0.85.md](v0.85.md) and [manual-ja.md](../manual-ja.md).

Stage 1 adds a Bluetooth Classic RFCOMM Serial Port Profile server for the
Pico 2 W onboard CYW43. The fixed discovery name is CPB-PicoCalc.

## Architecture

- Pico SDK 2.3.1 pico_btstack_cyw43 and pico_btstack_classic
- existing pico_cyw43_arch_lwip_threadsafe_background for Wi-Fi coexistence
- Classic-only link; BLE/GATT is not linked
- SDP Serial Port service record on RFCOMM server channel 1
- SSP Just Works pairing; legacy fixed-PIN pairing is rejected
- Pico SDK flash TLV link-key database for bond persistence
- fixed-capacity RX/TX rings with overflow counters
- UI-only echo/test behavior, separate from the transport core

Bluetooth starts OFF. Enabling it lazily initializes the shared CYW43 context
without enabling Wi-Fi STA mode. Wi-Fi may later use the same background async
context. Disabling Bluetooth powers HCI off without deinitializing CYW43 or
disconnecting Wi-Fi.

The Control Center test sends CPB Bluetooth SPP Stage 1 on connection, echoes
PC input, records RX/TX counts and can send an explicit test message.

Stage 1 does not add Bluetooth to the CPB console, XMODEM/YMODEM, file transfer,
BLE UART, HID, A2DP, or multiple simultaneous SPP clients. STANDBY disconnects
SPP and leaves Bluetooth OFF after wake.
