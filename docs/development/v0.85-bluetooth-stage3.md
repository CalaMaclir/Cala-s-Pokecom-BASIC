# Version 0.85 Bluetooth Stage 3

> This document records the development stage. Its early capacity figures are
> historical. For final Version 0.85 behavior, see [v0.85.md](v0.85.md) and
> [manual-ja.md](../manual-ja.md).

Stage 2のBluetooth SPP Consoleを、既存XMODEM/YMODEM coreが利用するbinary serial transportへ拡張します。

- Bluetooth Consoleから入力されたXRECV/XSEND/YRECV/YSENDは同じSPP connectionを使用します。
- RX ownershipはConsole、Test Terminal、Transferの三者で排他的です。
- transfer開始前にConsole TXをbounded drainし、開始後はprotocol bytes以外をSPPへ出しません。
- 0x00～0xffをCR/LF変換、ANSI decode、echo、Ctrl+C/BREAK処理なしで転送します。
- TX packetはqueueへ全体を投入できる場合のみ成功し、部分投入を成功扱いしません。
- Stage 1のCAN_SEND_NOW schedulerと同期callback/reentrancy対策を再利用します。
- success、cancel、timeout、disconnect、protocol errorの全経路でConsole ownershipへ戻ります。
- ローカル操作のAUTO route（USB CDC優先、未接続時UART0）は維持します。
- Ctrl+C/BREAK時だけREPL/runtime境界でaudio_stop()を実行します。END/STOPと一般runtime errorではbackground audioを維持します。

対象外: BLE、OBEX、PAN、HID、A2DP、multi-client SPP、専用Windowsアプリ、Bluetooth MSC、directory sync、automatic backup。
