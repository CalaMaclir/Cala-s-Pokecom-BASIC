# Version 0.90 Stage 1

## Navigation, Command History and File Management

Version 0.90 Stage 1 adds the shared navigation and file-management foundation for the later full-screen editor.

### Control Center navigation

- Up／Down: one item
- Shift+Up／Shift+Down: one visible page
- Selection is clamped to `0..count-1`, and the viewport offset is normalized after every move.
- The common `menu_scroll` implementation is used by Files, Wi-Fi scan, Bluetooth live scan, Paired Devices, program/transfer pickers, and the Control Center list.
- PicoCalc has no physical PGUP／PGDN keys; the UI names the actual Shift combinations.

### BASIC command history

- 24 entries, session-only; reboot starts with an empty history.
- Empty commands and consecutive exact duplicates are suppressed.
- Up selects older commands and Down selects newer commands.
- The draft present before the first Up is restored when Down returns past the newest entry.
- Recalled commands remain fully editable with Left／Right, Home／End, Backspace, Delete, and normal character insertion.
- USB CDC／UART ANSI `ESC [ A` and `ESC [ B` reuse the existing terminal-key decoder.
- Fixed storage cost is 24 × 224-byte entries plus one 224-byte draft; no heap allocation is used.

### Files

Left／Right switches between:

- `FILES [PROGRAMS]`: `.BAS` programs, preserving Enter Load, R Run, and Quick Load function-key assignment.
- `FILES [DIRECTORY]`: visible root regular files and directories with byte size or `<DIR>`.

Available operations:

- N: Rename
- Delete: confirmation with Cancel selected by default
- I: File Info (name, type, size), displayed below the list without leaving Files
- F: Refresh

Rename and Delete are root-file operations only. Directories are displayed and may be inspected, but directory navigation and directory mutation are intentionally not implemented in Stage 1. ProgramStore and several storage APIs assume the SD root; changing that invariant here would risk transactional save and editing-session recovery.

Rename starts with the existing file name selected as editable text, so small
name or extension changes do not require retyping the whole name.

Mutations are rejected for:

- active/current program files
- ProgramStore work files
- `RMBASIC.SES`, `RMBASIC.CFG`, `RMBASIC.BAK`
- session and transfer staging/backup files
- invalid names, existing rename targets, non-regular files
- USB MSC host ownership, unavailable storage, or busy storage
