# Version 0.85 Bluetooth Stage 2

> This document records the development stage. For final Version 0.85 behavior,
> see [v0.85.md](v0.85.md) and [manual-ja.md](../manual-ja.md).

Stage 1の実機PASS済みBluetooth Classic RFCOMM/SPP transportをCPB Console I/Oへ統合します。

- LCDはBluetooth接続中も維持します。
- USB CDC/UART0の既存ConsoleModeは変更しません。
- Bluetooth Consoleは独立した出力fan-outです。
- REPLの1行は最初に入力したKeyboard/USB-UART/Bluetooth transportが所有します。
- runtime入力はUSB/UARTとBluetoothで同じANSI decoder pathを使い、Ctrl+CはBREAK、通常文字はPAUSE/INKEYへ渡します。
- Normal modeではConsole、Test Terminal中はTest TerminalがSPP RXを排他的に所有します。所有権変更時はRX bufferをclearし、二重消費を防ぎます。
- Stage 1のCAN_SEND_NOW schedulerを再利用し、TX ringは2048 bytes、Console backpressure待ちは最大25 msです。timeout/disconnectで本体を永久blockしません。
- Bluetoothは起動時OFFです。Disable/STANDBYではConsole routeとRFCOMM状態を解除します。
- Bluetooth経由XMODEM/YMODEM、BLE、A2DP、HID、複数SPP clientはStage 2対象外です。
